# SEO Metadata Auditor Skill

## Purpose

Audit page titles, meta descriptions, OG tags, robots directives, and local SEO basics.

## When to Use

- Before staging deployment
- After new routes are added
- When metadata changes
- To ensure SEO best practices

## What to Check

### 1. Meta Titles

- Present on every page
- 50–60 characters (fits in search results)
- Keyword-rich (includes main topic)
- Brand name included (if relevant)
- Unique per page (not duplicated)

**Good example:**
```html
<title>Pricing | DirectCare Indy - Transparent DPC Membership</title>
```

**Poor example:**
```html
<title>Page</title>
```

### 2. Meta Descriptions

- 150–160 characters (fits in search results)
- Compelling call-to-action
- Accurate summary of page content
- Includes primary keyword
- Unique per page

**Good example:**
```html
<meta name="description" content="Compare our transparent pricing plans for individuals, families, and employers. No hidden fees—see exactly what you'll pay. Join DirectCare Indy today." />
```

### 3. Open Graph Tags (Social Sharing)

```html
<!-- Required -->
<meta property="og:title" content="Page Title" />
<meta property="og:description" content="Short description" />
<meta property="og:image" content="https://example.com/image.jpg" />
<meta property="og:url" content="https://example.com/page" />

<!-- Optional but good -->
<meta property="og:type" content="website" />
<meta name="twitter:card" content="summary_large_image" />
```

### 4. Canonical URLs

- Every page should have a canonical tag
- Prevents duplicate content issues
- Points to primary version of page

```html
<link rel="canonical" href="https://directcareindy.com/pricing" />
```

### 5. Robots Directives

Check `robots.txt` and `robots` meta tag:

```html
<!-- Allow indexing (default; usually not needed) -->
<meta name="robots" content="index, follow" />

<!-- Noindex for internal pages -->
<meta name="robots" content="noindex, nofollow" />
```

### 6. Sitemap

- `public/sitemap.xml` should exist
- All public routes included
- No noindex routes included
- Auto-generated by `next-sitemap` (postbuild script)

Verify: Visit `/sitemap.xml`

### 7. Structured Data (Schema.org)

Check for:
- Organization schema (company info)
- LocalBusiness schema (clinic location)
- BreadcrumbList (navigation)
- FAQPage (if FAQ present)

Example:
```json
{
  "@context": "https://schema.org",
  "@type": "LocalBusiness",
  "name": "DirectCare Indy",
  "address": "7911 N. Michigan Rd., Indianapolis, IN 46268",
  "telephone": "(317) 956-6288",
  "url": "https://directcareindy.com"
}
```

### 8. Local SEO Basics

- Google Business Profile link (if applicable)
- Address in footer (standardized format)
- Phone number clickable `tel:` link
- Local keywords in copy ("Indianapolis", neighborhood names)

## Audit Checklist

```
Meta Titles:
- [ ] Homepage title present and keyword-rich
- [ ] Pricing page title includes "Pricing"
- [ ] Membership page title present
- [ ] FAQ title present
- [ ] All titles 50-60 characters
- [ ] No duplicate titles across pages

Meta Descriptions:
- [ ] Homepage description compelling
- [ ] All pages have descriptions
- [ ] Descriptions 150-160 characters
- [ ] Descriptions include primary keyword
- [ ] No duplicate descriptions

OG Tags:
- [ ] og:title present on key pages
- [ ] og:description present
- [ ] og:image present and valid URL
- [ ] og:image is 1200x630px or similar
- [ ] Twitter cards present

Robots & Indexing:
- [ ] Sitemap.xml exists and valid
- [ ] robots.txt present
- [ ] Public pages set to index, follow
- [ ] Internal/draft pages noindex
- [ ] Canonical tags present on key pages

Local SEO:
- [ ] Address in standardized format
- [ ] Phone number clickable (tel: link)
- [ ] Local keywords in page copy
- [ ] Contact page complete
- [ ] Google Business Profile linked (if applicable)

Schema:
- [ ] Organization schema present
- [ ] LocalBusiness schema present
- [ ] FAQ schema present (if FAQ page)
- [ ] Structured data valid (check with Schema.org tool)
```

## Tools to Use

**Schema.org Validator:**
https://schema.org/

**Google Mobile-Friendly Test:**
https://search.google.com/test/mobile-friendly

**Meta Tag Preview (online):**
Search "meta tag preview generator"

**Sitemap Validator:**
https://www.xml-sitemaps.com/validate-xml-sitemap.html
